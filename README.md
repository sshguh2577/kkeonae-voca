# 꺼내보카 '아침 영어'

이 가지(`brief`)에는 꺼내보카 앱이 아침마다 받아 가는 브리핑 파일 `brief.json`만 있어요.
앱 코드는 `main` 가지에 있어요.

- 날마다 새벽에 Claude가 금융·보험, 토목, 세계 소식을 하나씩 골라 쉬운 영어로 새로 써요.
  기사 문장을 옮기지 않고, 고른 기사의 이름과 주소를 `source`에 적어요.
- 문장마다 한국어 해석(`ko`)이 있고, 소식마다 알아 둘 단어 2~4개(`words`)와 '오늘의 질문'(`question`)이 있어요.
- 최근 7일치만 두고, 최신 날짜가 맨 앞이에요.
- 날씨는 이 파일에 없어요. 앱이 폰에서 지금 있는 곳의 날씨를 직접 받아요(Open-Meteo).
- 올리기 전에 `python3 check_brief.py brief.json`으로 형식을 검사해요.
