# 꺼내보카 '오늘의 지문'

이 가지(`reads`)에는 꺼내보카 앱이 하루에 한 번 받아 가는 지문 파일 `reads.json`만 있어요.
앱 코드는 `main` 가지에 있어요.

- 지문의 문장과 해석은 모두 새로 쓴 것이에요.
- 지문마다 맞춰 쓴 Day 번호(`need`)가 있어요. 앱은 그 Day까지 단어를 한 번씩 다 꺼내 본 뒤에 그 지문을 보여 줘요.
- 뜻풀이(`gloss`)에는 직접 쓴 뜻만 있어요. 단어장에 있는 낱말의 뜻은 앱이 폰 안의 단어장에서 찾아 보여 줘요.
- 파일을 고칠 때마다 `rev` 숫자를 하나 올려요. 같은 `id`의 지문은 내용만 바뀌고 읽은 기록은 남아요.
